# 공통 UI 4차 분리 — 2026-10-29

## 범위

UI 0.4.1에 `AlertDialog`와 `PopupChoice`를 추가했다. 공통 컴포넌트는 총 11개다.
앱 30개 파일의 import를 패키지로 전환하고 기존 두 구현과 CSS를 제거했다.

| 패키지 경로 | API | 역할 |
| --- | --- | --- |
| `@muajigyeong/ui/modal-dialogs` | `AlertDialog`, `BaseDialogProps`, `AlertDialogProps`, `AlertDialogOptions` | 제목·본문·사용자 정의 버튼·외부 상태를 받는 네이티브 모달 |
| `@muajigyeong/ui/popup-choice` | `PopupChoice`, `PopUpChoiceProps` | 라디오 옵션의 임시 선택, 확인 시 확정, 취소 시 복원 |

프로필·조건 묶음·장소 비교·주변 교통·리뷰·여행·로그인 등 업무별 본문과 데이터 처리는
앱에 남는다. 각 화면은 UI 패키지의 대화상자 틀을 사용한다.
사용처가 없고 열기 버튼이 숨겨진 `PopupModalDialog`, Next.js 이동을 포함하는
`ProfileAutoFilterDialog`, 갤러리·리뷰 라이트박스는 이번 공개 API에서 제외했다.
후속 라이트박스 분리는 이미지 탐색·확대·포커스 동작을 함께 설계해야 한다.

## 사용법

```tsx
"use client";

import { useState } from "react";
import { AlertDialog, type BaseDialogProps } from "@muajigyeong/ui/modal-dialogs";
import { PopupChoice } from "@muajigyeong/ui/popup-choice";

const OpenButton: BaseDialogProps["OpenButton"] = props => (
  <button {...props} type="button">편집</button>
);

export default function Example() {
  const controller = useState(false);
  return <>
    <AlertDialog title="편집" OpenButton={OpenButton} modalController={controller}
      options={{ initialFocus: "title" }}>
      <p>업무별 입력과 저장 처리는 앱에서 구현합니다.</p>
      <button type="button" onClick={() => controller[1](false)}>확인</button>
    </AlertDialog>
    <PopupChoice label="정렬" name="sort" options={["이름순", "최신순"]} />
  </>;
}
```

- `modalController`를 생략하면 내부 상태를 사용한다.
- `OpenButton`은 받은 `ref`와 `onClick`을 실제 버튼에 전달해야 한다.
  버튼은 컴포넌트 바깥에서 선언하거나 `useCallback`으로 유지한다.
  매 렌더마다 새 버튼 컴포넌트를 만들면 버튼이 재마운트되고 포커스를 잃을 수 있다.
- `onCancel`은 Escape·바깥 클릭·닫기 버튼에, `onAfterClose`는 네이티브 닫힘에 대응한다.
  확인 동작은 자식 버튼에서 처리한다. 기존 `onOK`는 호출되지 않는 예약 API이므로
  호환성을 위해 유지하고 JSDoc에 deprecated로 표시했다.
- 열기 요소가 사라지거나 비활성화될 때 `returnFocusRef`로 복귀 위치를 지정한다.
- `bodyProps`, `className`, 사용자 정의 `CloseButton`, 제목 숨김과 닫기 버튼 배치를 유지한다.
- `PopupChoice`는 기존과 같이 내부 상태로 선택을 보관한다. 외부 제어와 변경 콜백을
  제공하는 API로 확장하지 않았다. 여러 인스턴스에는 서로 다른 `name`을 지정한다.
- 독립 프로젝트에서는 `@muajigyeong/ui/theme.css`를 불러오거나 같은 테마 변수를 제공한다.
  앱은 기존 전역 테마를 그대로 사용한다.

## 이전 시 보완한 사항

ESM과 기존 JSX 구조·스타일·주석을 보존했다. 새 API 설명은 JSDoc으로 추가했다.
`useFocusTrap`과 CSS 클래스 매핑 도우미는 패키지 내부로 복사해 앱 경로 의존성을 제거했다.
앱의 훅과 도우미는 라이트박스 등 다른 사용처가 있어 유지한다.

- 최신 원격의 훅 순서 안정화와 `returnFocusRef`, 숨겨진 열기 버튼을 건너뛰는 포커스 복귀를 보존했다.
- 숨김 제목의 스타일을 CSS Module 안에 포함해 앱의 전역 클래스 없이도 동작한다.
- `PopupChoice` 제목을 고유 ID와 `aria-labelledby`로 연결했다.
- 선택 대화상자가 사용하는 `--teal-600`, `--teal-800`을 기본 테마에 포함했다.

- UI 타입 검사·ESM 빌드·패키지 생성·Storybook 정적 빌드 통과.
- 기존 컴포넌트와 대화상자를 포함한 11개 컴포넌트 브라우저 검증 통과.
- Tab/Shift+Tab, Escape, 제목 포커스, 열기 버튼 복귀, 중첩 모달의 안쪽부터 닫기 확인.
- 제어 상태·확인과 취소 콜백·선택 복원·빈 옵션·ID 중복 방지 확인.
- 모바일 긴 내용 스크롤, 고대비 표시, 모든 문서 예제의 React 컴포넌트 이름 확인.

- 최신 앱 원격 18개 커밋을 통합하고 추가된 대화상자 사용처까지 이전했다.
